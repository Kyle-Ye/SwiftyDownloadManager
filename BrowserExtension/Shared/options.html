When does SDM ask?

Opening a matching address through the address bar or a page redirect shows a confirmation after the file check. Recognized link clicks and download buttons go directly to SDM.

You can always choose Continue in browser on the confirmation page. A website’s same-origin download link or an explicit Download with SDM action works independently of these lists.

These rules apply to direct HTTP and HTTPS file links, including download buttons that use window.open. Embedded video playback and streaming segments are not captured.
